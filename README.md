## 🚀 Overview
An AI-powered Movie Review Analytics Platform that analyzes audience reviews, predicts sentiment, detects emotions, and generates actionable insights through interactive dashboards.

Movie Review Analytics is a machine learning-based web application built using Python and Streamlit. The platform allows users to submit movie reviews, automatically classifies them into Positive, Neutral, or Negative categories, and provides detailed analytics on audience perception.

The system combines Natural Language Processing (NLP), Sentiment Analysis, Emotion Detection, and Interactive Data Visualization to transform raw reviews into meaningful insights.

---

## ✨ Features

### 🔍 Sentiment Analysis

* Classifies reviews as Positive, Neutral, or Negative
* Provides confidence scores for predictions
* Uses Logistic Regression with TF-IDF Vectorization

### 😊 Emotion Detection

* Identifies dominant emotions from user reviews
* Powered by Transformer-based NLP models
* Displays emotion strength and distribution

### 📊 Interactive Analytics Dashboard

* Audience Mood Meter
* Sentiment Distribution Charts
* Movie Quality Radar
* Trending Movies Analysis
* Top Rated Movies Ranking

### 🧠 AI-Generated Insights

* Automatically generates audience verdicts
* Summarizes overall viewer reactions
* Provides recommendation insights

### ☁️ Google Sheets Integration

* Stores reviews in real time
* Maintains centralized review database
* Supports live updates and analytics

### 🎨 Modern User Interface

* Built with Streamlit
* Interactive charts using Plotly
* Responsive dashboard design

## ⚙️ How It Works

1. User enters a movie name and review.
2. Review text is preprocessed using NLP techniques.
3. TF-IDF converts text into numerical features.
4. Logistic Regression predicts sentiment.
5. Transformer model detects emotions.
6. Results are visualized through interactive dashboards.
7. Review data is stored in Google Sheets and SQLite.
